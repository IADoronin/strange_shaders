# strange_shaders — пространства с различной топологией

Шейдер (raymarcher), который рисует не объект, а **само пространство** с заданной
топологией, плюс сопроводительная теория с выводом уравнений и тестами.

Главная идея: луч движется в универсальном накрытии $\tilde X=\mathbb{R}^3$, а
координата сворачивается в фундаментальную ячейку перед опросом поля расстояний
(SDF). Разные группы склейки $\Gamma$ дают разные топологии при **одном и том же**
коде рендера: $X=\tilde X/\Gamma$.

## Файлы

| Файл | Что это |
|------|---------|
| `topology_shader.html` | Самодостаточный WebGL-raymarcher (без зависимостей). Двойной клик — и работает офлайн. |
| `topology_theory.ipynb` | Теория с уравнениями и визуализациями: накрытия и фактор-пространства, плоский тор $T^n$, скрученный тор, орбифолды, Мёбиус/Клейн, обзор $S^3/H^3$, мост к raymarching, тесты «звезда+планета». |
| `test_topology.py` | Эталонная реализация fold-формул + автотесты (`python test_topology.py`). |

## Шейдер: управление

- `1` — плоский 3-тор $T^3$ (трансляции)
- `2` — зеркальный орбифолд (отражающие стенки)
- `3` — скрученный $T^3$ (монодромия $R_x(\pi)$)
- `4` — звезда + планета в $T^3$ (одна звезда видна как решётка образов)
- `5` — обычное $\mathbb{R}^3$ без склейки (для сравнения: планета одна)
- `[` / `]` — период заворота $L$ (через сколько луч «выходит с другой стороны»; больше = копии дальше)
- мышь — осмотр, колесо — скорость, `Space` — пауза

Оранжевая асимметричная «F» делает видимыми поворот (скрученный тор) и отражение
(орбифолд): в обычном $T^3$ все копии одинаковы, в скрученном — через одну
перевёрнуты, в зеркальном — отражены.

## Теория и тесты

```bash
python test_topology.py        # 13/13 автотестов fold-формул
```

Ноутбук открывается в Jupyter/VSCode; формулы — в LaTeX, визуализации — matplotlib.
Космологический тест «одна звезда и планета» в $T^3$: одиночная звезда видна как
решётка образов («зеркальный зал» / космическая кристаллография), число образов
в горизонте $R$ растёт как $\tfrac{4}{3}\pi R^3/L^3$.
