# topology_native — Rust + wgpu (Metal)

Нативный raymarcher топологических пространств. Тот же подход, что и в браузерной
версии (`../topology_shader.html`), но на низком уровне: **Rust + wgpu**, на macOS
исполняется через **Metal**. Вся логика рендера — во фрагментном WGSL-шейдере
(`src/shader.wgsl`); хост (`src/main.rs`) только открывает окно, читает ввод и
гоняет один полноэкранный треугольник.

## Главная фича: оптика «заторенной вселенной» (режим 6)

Локально мир обычный — рядом планета (освещённая своим солнцем поверхность). Но
из-за топологии $T^3$ **звёздное небо состоит из повторяющихся образов одной
звезды**. Светящиеся объекты рисуются НЕ как геометрия, а как **точечные источники
с PSF**:

- яркость $\propto L_\star/d^2$ (закон обратных квадратов) — далёкая звезда тусклее;
- угловой размер пятна не опускается ниже ~пикселя: ядро растёт с дистанцией
  $\text{core}=\max(R_\star,\,k_{\text{ang}}\,t)$, поэтому звезда **теряет яркость,
  а не исчезает** при суб-пиксельном размере;
- вклад копится вдоль луча; делитель $t^3$ при ядре $\propto t$ даёт суммарный
  вклад образа $\propto 1/t^2$;
- HDR + тон-маппинг по экспозиции $1-e^{-\text{hdr}\cdot E}$; планета сглажена
  SSAA 2×2, чтобы далёкие копии не мерцали.

## Сборка и запуск

Нужен Rust (`rustup`); на macOS — Xcode Command Line Tools.

```bash
cargo run --release
```

Первая сборка тянет крейты (wgpu, winit, …) — это нормально.

## Управление

Топологию можно выбрать в **строке меню → «Топология»** (нативное меню macOS,
с галочкой текущего режима) или клавишами:

| Клавиши | Действие |
|---|---|
| `1`–`6` | режимы: 1 T³ · 2 зеркальный орбифолд · 3 скрученный T³ · 4 звезда+планета(T³) · 5 R³ · 6 **заторенная вселенная** |
| `[` `]` | период заворота $L$ (через сколько луч «выходит с другой стороны») |
| `-` `=` | экспозиция (режим 6) |
| `,` `.` | светимость звезды (режим 6) |
| мышь | осмотр · колесо — скорость · `Space` — пауза · `Esc` — выход |

## Что попробовать в режиме 6

- Увеличить период `]` — копии звезды разъезжаются, небо «глубже».
- `,`/`.` и `-`/`=` — поймать баланс: ближняя звезда сияет, дальние видны как
  тусклые точки и **не пропадают** при отдалении.

## Упаковка в macOS-приложение (.app)

```bash
bash packaging/package.sh
```

Соберёт release-бинарь и упакует в `dist/`:
- `TopologyNative.app` (ad-hoc подписан),
- `TopologyNative-<ver>-macos-arm64.zip`,
- `TopologyNative-<ver>-macos-arm64.dmg` (с симлинком на `/Applications` — drag-install).

Артефакты локальные (`dist/` в .gitignore). Подпись ad-hoc (без сертификата Apple),
поэтому при первом запуске Gatekeeper может ругаться — открыть через ПКМ → «Открыть».

## Стек

`wgpu` (Metal/Vulkan/DX/GL), `winit` (окно/ввод), `pollster` (async→sync),
`bytemuck` (uniform-буфер). Шейдер — WGSL.
